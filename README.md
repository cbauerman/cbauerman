
# About me

## Summary

I am a frontend engineer with a decade of experience building web applications and shared frontend infrastructure. Currently working at [NVIDIA](https://github.com/NVIDIA).

## Notable Work on GitHub

I've worked on open source projects while employed at [Automattic](https://github.com/automattic) and [NVIDIA](https://github.com/NVIDIA).

- [wp-calypso](https://github.com/Automattic/wp-calypso) from 2018 through 2022 I was a frequent contributor to the React WordPress.com frontend.
	- You can browse [my ~300 PRs directly here](https://github.com/search?q=repo%3AAutomattic%2Fwp-calypso+is%3Apr+author%3Acbauerman&type=pullrequests).

- [NVIDIA Public Icons](https://github.com/NVIDIA/icons) I am currently the primary maintainer of these React packages for rendering NVIDIA GUI Icons.
	- Check out [the contribution guidelines here](https://github.com/NVIDIA/icons/blob/main/CONTRIBUTING.md).
